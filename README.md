# Lexito pentru Claude

Comenzile Lexito în meniul `/` din Claude. Pluginul lucrează prin conectorul Lexito: fără conector, comenzile nu au date.

## Instalare

**claude.ai și Claude Desktop:** Customize → Plugins → Add → din GitHub, `danieltamas/lexito-plugin`.

**Claude Code:**

```
/plugin marketplace add danieltamas/lexito-plugin
/plugin install lexito@lexito
```

Conectorul Lexito se adaugă separat, din contul tău Lexito.

## Comenzi

| Comandă | Ce face |
|---|---|
| `/azi` | Ședințele și termenele de azi și de mâine |

Lista crește odată cu Lexito.

## Date

Pluginul conține doar instrucțiuni pentru Claude. Nu stochează și nu trimite date; tot ce vede Claude vine din conectorul Lexito, cu permisiunile contului tău.
